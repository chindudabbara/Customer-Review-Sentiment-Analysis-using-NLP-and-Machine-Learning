# Customer-Review-Sentiment-Analysis-using-NLP-and-Machine-Learning
* Designed an NLP pipeline to classify reviews as positive, negative, or neutral using TF-IDF vectorization and ML algorithms.
• Evaluated Logistic Regression, Naive Bayes, and SVM; selected the best model using Accuracy, Precision, Recall, and F1 
  Score, achieving 77.4% accuracy and a 73.7% F1-score.
• Integrated the final model into a Streamlit app enabling real-time sentiment prediction on new customer reviews
